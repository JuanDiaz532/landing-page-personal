# Mi Landing Page Personal
Página web simple de presentación personal, creada como parte de un
proyecto de práctica en control de versiones con Git y GitHub.

## Descripción
Este sitio incluye secciones de inicio, sobre mí, proyectos y contacto,
construido con HTML, CSS y JavaScript básico.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Cómo verlo
1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
